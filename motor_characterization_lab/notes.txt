pendulum in pwm-dir mode
| Raspberry Pi            | BD65496MUV   | Purpose             |
| ----------------------- | ------------ | ------------------- |
| GPIO18, physical pin 12 | **INA**      | 20 kHz hardware PWM |
| GPIO23, physical pin 16 | **INB**      | Direction           |
| GPIO24, physical pin 18 | **PS**       | Enable / coast      |
| 3.3 V                   | **PWM/MODE** | HIGH → EN/IN mode   |
| 3.3 V                   | **VCC**      | Driver logic power  |
| GND                     | **GND**      | Common ground       |
| GPIO17, pin 11          | Encoder A    | Quadrature encoder  |
| GPIO27, pin 13          | Encoder B    | Quadrature encoder  |
| Motor PSU +             | VIN          | Motor supply        |
| Motor PSU −             | GND          | Common with Pi GND  |
| Motor                   | OUTA / OUTB  | Motor terminals     |
